# Notebooks

Run from any subdirectory after `pip install -e .` from the repo root, or use the bootstrap cell at the top of each notebook (adds the repo root to `sys.path` and defines `FIG_DIR` / `REPORT_FIG_DIR`).

| Folder | Contents |
|--------|----------|
| `experiments/` | End-to-end BO, MFBO, and final experiment runs |
| `scenarios/` | Synthetic stress tests and Victoria-style realistic env |
| `heuristics/` | Heuristic baselines for retardant placement |
| `parameterization/` | SR `(s, r, δ)` mapping and illustration notebooks |
| `archive/` | Earlier exploratory / superseded notebooks |

See the root [README](../README.md) for setup and suggested starting points.
